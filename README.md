## Project Overview

This project demonstrates the deployment of a cloud-hosted website using Microsoft Azure Infrastructure as a Service (IaaS).

The website is hosted on an Ubuntu Linux Virtual Machine running the Nginx web server. A custom domain (zestra.fun) has been configured and secured using SSL/TLS encryption.
